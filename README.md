# Get INVOLVED! ม.3 - แบบฝึกหัดภาษาอังกฤษออนไลน์ (ทวพ. - TWP)
### เวอร์ชัน 2.0.0 (Account Authentication, Progressive E-Certificate & Google Sheets Sync)

เว็บแอปพลิเคชันแบบฝึกหัดภาษาอังกฤษออนไลน์ ระดับชั้นมัธยมศึกษาปีที่ 3 (ม.3) พัฒนาตามหลักสูตรหนังสือเรียน **Get INVOLVED!** โดย **บริษัท สำนักพิมพ์ ไทยวัฒนาพานิช จำกัด (TWP)** 
รองรับเนื้อหาตาม **แผนการสอน ม.3 ภาคเรียนที่ 2 (Unit 5 - Unit 8)**:
- **Unit 5: A Better Place** (สิ่งแวดล้อม, ชนเผ่า Evenki ในไซบีเรีย, Green Audit, และ Zero/First Conditional)
- **Unit 6: Experience** (ประสบการณ์ชีวิตและการผจญภัย, ละครเวที, และ Present Perfect กับ ever/never)
- **Unit 7: My Stuff** (สิ่งของ วัสดุ คุณสมบัติ, ของขวัญความทรงจำ, และ Present Perfect กับ for/since)
- **Unit 8: Responsibility** (หน้าที่ งานบ้าน, การช่วยเหลือผู้อื่น, และ have to / don't have to / will / going to / -ed / -ing adjectives)

## 🌟 จุดเด่นและระบบความปลอดภัยที่ได้รับการปรับปรุงจาก ม.1 และ ม.2

1. **ดีไซน์ใหม่สไตล์ Organic & Mature (ไม่เหมือนเทมเพลต AI)**:
   - ปรับชุดสีเป็น **Deep Slate Navy ตัดกับ Sunset Amber / Warm Orange** สะท้อนอัตลักษณ์ของนักเรียน ม.3 ที่เตรียมตัวสอบเข้า ม.ปลาย
   - ปุ่มกดแบบ **Tactile 3D Feel** มีระยะยุบตัวและน้ำหนักเมื่อแตะบนจอมือถือ
   - เฉลยแบบ **Tutor Insight Coaching** ชี้จุดสังเกตและดักหลอกข้อสอบแบบเป็นธรรมชาติ

2. **ระบบบัญชีนักเรียน (Student Account Authentication)**:
   - ป้องกันคะแนนสับสน/ไม่ต่อเนื่อง ด้วยระบบ Email & Password
   - ระบบ **Email Auto-Normalization (.trim().toLowerCase())** ป้องกันข้อผิดพลาดจากการพิมพ์ตัวพิมพ์ใหญ่บนคีย์บอร์ดมือถือ
   - ตรวจจับและจับคู่ชื่อ-นามสกุล และโรงเรียนอัตโนมัติจากฐานข้อมูล
   - รองรับการนำเข้ารายชื่อนักเรียนจาก Excel (.xlsx) / CSV

3. **ระบบแบบฝึกหัดและการโต้ตอบ (Mobile Thumb-Friendly)**:
   - **Part 1 Vocabulary Matching**: ระบบ Tap-to-Pair แตะเลือกคำศัพท์แล้วแตะความหมาย ไม่หลุดหรือกระตุกเหมือน Drag & Drop บนมือถือ
   - **Part 2 Multiple Choice**: 4 ตัวเลือก พร้อมระบบแสดงคำอธิบายเฉลยละเอียดภาษาไทยทันที
   - **Part 3 Dialogue & Grammar**: เติมคำในช่องว่างพร้อมระบบ Normalized Check ป้องกันการผิดเพราะเว้นวรรคเกิน

4. **ระบบเกียรติบัตรอิเล็กทรอนิกส์อัจฉริยะ (Progressive E-Certificate)**:
   - ออกเกียรติบัตรอัตโนมัติเมื่อทำแบบฝึกหัดครบทั้ง 4 Units (5, 6, 7, 8)
   - เรนเดอร์ด้วย **High-DPI Canvas (2X Resolution)** ตัวอักษรและโลโก้คมชัด ไม่เบลอเมื่อดาวน์โหลดหรือพิมพ์
   - ระบบตรวจสอบฟอนต์ล่วงหน้า (`document.fonts.ready`) ป้องกันปัญหาสระลอยหรือฟอนต์เพี้ยน
   - มีระบบค้นหาและตรวจสอบเกียรติบัตรย้อนหลังได้ตลอดเวลา

5. **ระบบบริหารจัดการสำหรับครูผู้สอน (Teacher Dashboard)**:
   - แดชบอร์ดสรุปผลคะแนนแบบเรียลไทม์ เชื่อมโยงกับ Google Sheets
   - ตัวกรองคะแนนแยกรายบท (Units 5, 6, 7, 8), ค้นหาชื่อ/โรงเรียน
   - ส่งออกข้อมูลเป็นไฟล์ **Excel (.xlsx)** หรือ **CSV** ได้ทันที
   - นำเข้ารายชื่อนักเรียนใหม่เข้าฐานข้อมูลได้ผ่านการอัปโหลดไฟล์

6. **ระบบสำรองข้อมูลและป้องกันข้อมูลสูญหาย (LocalStorage Auto-Save & Offline Queue)**:
   - บันทึกความคืบหน้าของนักเรียนลงเครื่องทันทีเมื่อตอบแต่ละข้อ หากเน็ตหลุดหรือปิดเบราว์เซอร์ คำตอบจะไม่หาย
   - ส่งข้อมูลซิงก์ขึ้น Google Sheets อัตโนมัติเมื่อส่งงาน

## 📋 ขั้นตอนการติดตั้ง Google Sheet: `TWP_GetInvolved_M3_Database`

### ขั้นที่ 1: สร้าง Google Sheets ใหม่
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตใหม่
2. ตั้งชื่อสเปรดชีตว่า: **`TWP_GetInvolved_M3_Database`**

### ขั้นที่ 2: ติดตั้ง Apps Script
1. ไปที่แถบเมนูด้านบนของ Google Sheet -> คลิก **"ส่วนขยาย" (Extensions)** -> **"Apps Script"**
2. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs` ออก
3. เปิดไฟล์ `Code.gs` (หรือ `google-apps-script.txt` ที่เตรียมไว้ให้) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดมาวาง
4. กดไอคอน **"บันทึกโครงการ" (Save)** (รูปแผ่นดิสก์ หรือกด Ctrl + S)

### ขั้นที่ 3: สั่งรัน Setup เพื่อสร้างโครงสร้างตารางอัตโนมัติ
1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน **`setupAllSheets`**
2. คลิกปุ่ม **"เรียกใช้" (Run)**
3. Google จะขอสิทธิ์การเข้าถึง (Authorization Required):
   - คลิก **"ตรวจสอบสิทธิ์" (Review permissions)**
   - เลือกบัญชี Google ของท่าน
   - คลิก **"ขั้นสูง" (Advanced)** -> คลิก **"ไปที่ โครงการที่ไม่มีชื่อ (ไม่ปลอดภัย)"**
   - คลิก **"อนุญาต" (Allow)**
4. เมื่อรันเสร็จ สเปรดชีตจะถูกสร้างชีตขึ้นมาครบทั้ง 6 แผ่น พร้อมจัดรูปแบบคอลัมน์ให้อย่างสวยงาม:
   - `Students_DB` : ฐานข้อมูลนักเรียน (Email, รหัสผ่าน, ชื่อ-สกุล, โรงเรียน, สถานะ)
   - `Name_base` : ฐานข้อมูลสำหรับ Auto-lookup
   - `Login_Logs` : บันทึกประวัติการล็อกอิน
   - `Scores_Log` : บันทึกคะแนนแยกตามบทและข้อ
   - `Certificates` : ทะเบียนรหัสเกียรติบัตร
   - `Teacher_Config` : รหัสผ่านครูและตั้งค่าระบบ

### ขั้นที่ 4: การนำไปใช้งานเป็นเว็บแอป (Deploy Web App)
1. คลิกปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้" (Deploy)** ด้านบนขวา -> เลือก **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. คลิกที่รูปฟันเฟืองข้าง "เลือกประเภท" -> เลือก **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description)**: `TWP M3 Backend v2.0`
   - **ดำเนินการในฐานะ (Execute as)**: **`ฉัน` (Me / เจ้าของชีต)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน` (Anyone)** *(สำคัญมาก ต้องเลือก Anyone)*
4. คลิกปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. คัดลอก **URL เว็บแอป (Web app URL)** นำมาวางในหน้าเว็บแอป (คลิกปุ่ม "ตั้งค่าระบบ / Google Script URL" ที่มุมขวาบน หรือใน Teacher Dashboard)
